# 마이링크(MyLink) 사용자 시나리오

## 1. 방문자: 마이링크 페이지 방문 과정

### 1-1. 기본 열람 및 링크 이동
*   방문자는 특정 소유자의 마이링크 페이지에 접속하기 위해 `도메인.com/닉네임` URL을 브라우저에 주소창에 입력하고 이동한다.
*   방문자는 페이지 소유자가 누구인지 확인하기 위해 상단에 표시된 **유저네임(실제 이름)**과 **상세 소개글**을 읽는다.
*   방문자는 자신이 관심 있는 외부 사이트로 이동하기 위해 원하는 **링크 버튼**의 텍스트와 파비콘 아이콘을 직접 확인한다.
*   방문자는 원래 페이지의 접속 상태를 유지하기 위해 원하는 링크 버튼을 클릭하여 외부 사이트를 **새 탭(새 창)**으로 연다.

### 1-2. 예외 상황 (Edge Cases)
*   방문자는 올바른 페이지를 찾기 위해, 존재하지 않는 닉네임의 주소로 접속했을 때 나타나는 "존재하지 않는 페이지입니다"라는 에러 안내 화면을 확인한다.
*   방문자는 페이지의 현재 상태를 인지하기 위해, 소유자가 링크를 하나도 등록하지 않은 정상 주소에 접속했을 때 "아직 등록된 링크가 없습니다"라는 안내 메시지를 읽는다.

---

## 2. 소유자: 프로필 셋팅 및 링크 관리 과정

### 2-1. 로그인 및 프로필 설정 (인라인 편집)
*   소유자는 마이링크 서비스를 시작하기 위해 메인 화면에서 구글 계정 소셜 로그인 버튼을 클릭한다.
*   소유자는 방문자들에게 배포할 자신의 고유 접속 주소(`도메인.com/닉네임`)를 만들기 위해 초기 회원가입 프로세스에서 **닉네임**을 설정하고 가입을 마친다.
*   소유자는 방문자에게 노출될 자신의 실제 이름과 소개글을 최신 상태로 갱신하기 위해 대시보드 화면상에 위치한 **유저네임** 또는 **상세 소개글** 텍스트를 직접 클릭한다.
*   소유자는 변경된 프로필 내용들을 서버에 저장하기 위해 인라인 편집 상자에서 텍스트 수정을 마친 후 **엔터(Enter) 키**를 누르거나 마우스로 **입력창 외부 화면을 클릭(Focus out)**한다.

### 2-2. 링크 추가
*   소유자는 새로운 소셜 플랫폼이나 웹사이트를 방문자에게 공유하기 위해 대시보드 중앙의 **"링크 추가"** 버튼을 누른다.
*   소유자는 방문자에게 어떤 링크인지 명확히 알리기 위해 새로 생성된 빈 링크 항목의 제목을 클릭하여 인라인으로 **링크명**을 텍스트로 입력한다.
*   소유자는 방문자가 클릭 시 해당 위치로 정상 연결되게 하기 위해 URL 입력란을 클릭하여 인라인으로 **실제 연결 주소(URL)**를 입력한다.
*   소유자는 자신이 등록한 링크에 아이콘이 올바르게 나타나는지 검증하기 위해, URL 입력 완료 직후 구글 API를 통해 자동으로 불러와진 좌측의 **파비콘 이미지**를 확인한다.

### 2-3. 링크 수정 및 에러 대처
*   소유자는 오타가 났거나 목적지가 변경된 링크 정보를 고치기 위해 기존에 등록된 링크명이나 URL 텍스트를 클릭하여 인라인 편집 모드로 진입한다.
*   소유자는 작성한 수정 작업을 완료하기 위해 원하는 내용으로 바꾼 후 **엔터(Enter) 키를 누르거나 입력 폼 외부를 클릭**한다.
*   소유자는 올바르지 않은 주소 형식을 입력(예: `http://` 가 빠졌거나 형태가 이상할 때)했을 때, 정확한 형태의 주소를 다시 파악하고 기입하기 위해 화면상에 나타나는 **"올바른 URL 형식을 입력해주세요"**라는 에러 메시지를 확인한다.

### 2-4. 링크 삭제
*   소유자는 더 이상 운영하지 않거나 홍보 기간이 끝난 특정 사이트를 리스트에서 제외시키기 위해 해당 링크 항목 우측에 위치한 **"삭제"** 버튼을 클릭한다.
*   소유자는 실수로 링크를 삭제해버리는 상황을 방지하기 위해 화면 모서리나 팝업으로 나타나는 **"정말 삭제하시겠습니까?"** 안내 모달창에서 확인 버튼을 클릭한다.
